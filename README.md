# 揭棋（暗棋）· 单人双控

一个纯前端的中国象棋「揭棋」玩法网页游戏。只有一个人操作：先走红方，再走黑方，双方都由你下。
针对手机浏览器做了适配（竖屏直接玩，可加书签全屏）。

## 打开方式

直接双击 `index.html` 即可（无需服务器、无需安装任何依赖）。

- 手机上玩：把整个文件夹放到手机里用浏览器打开 `index.html`，或部署到任意静态服务器 / 局域网。
- 也可以放到 GitHub Pages、任何静态托管上，手机访问网址就能玩。

## 玩法（详见游戏内「规则」按钮）

- 棋盘是标准中国象棋棋盘，**目标仍是将军将死**，不是吃光棋子。
- 帅/将固定明摆在九宫原位；其余 15 颗棋子全部打乱，背面朝上放在己方半场原来的棋位上（暗子）。
- 每回合**二选一**：走一枚己方棋子（明子或暗子），或者翻开一枚位于己方界内的暗子；不能既翻又走。
- **卧底机制**：暗子未翻开时，按它所在棋位在常规象棋中的兵种行走（背面已经标出这个身份，双方都看得见）；
  翻开之后改按它真实的兵种行走，走法可能完全变样（车直走、马走日、炮隔子打……）。
- 暗子能走、能吃子、能将军；走完之后依然是暗子——吃子的一方不亮牌，被吃的才亮牌。
- 暗子一旦走出己方界内，就不能再被翻开了（**本方只能翻自己界内的暗子**）。
- **揭棋特色：士可以出九宫、象可以过河**，其余走法（塞象眼、蹩马腿、炮隔子打）不变。
- **将帅不得出九宫随意行走**；兵卒不可后退（过河后仍只能向前或左右走）。
- 明子吃暗子时，暗子先翻开、再移除；吃之前不知道它是什么子，有赌的成分。
- 炮可以拿暗子当炮架；**双方暗子在未翻开时都可以被自家棋子吃掉（自残）**。
- 将帅不能照面；被将军时必须应将（此时不能翻子）。

## 单人双控的操作方式

- 点自己的棋子（明子、暗子都可以）→ 棋盘上显示绿点（可走）/ 红圈（可吃）→ 点落点即走子。
- 选中一枚**位于己方界内的暗子**时，顶部会出现「翻开此暗子」按钮，点它即可翻子。
- 再点一次已选中的棋子可取消选中。
- 棋盘不区分你我，轮到哪一方就操作哪一方的棋子。
- 「翻转」按钮可手动换视角；「设置」里可以打开**自动翻转**，轮到谁就把谁转到屏幕下方，更接近真人左右手分开操作的感觉。

## 功能

| 功能 | 说明 |
| --- | --- |
| 新局 / 撤销 | 撤销可回退到任意历史局面（含翻子、吃子、将军计数） |
| 认输 | 直接判对方胜 |
| 视角翻转 / 自动翻转 | 单人双控时更好操作 |
| 被吃棋子 | 分开显示双方损失，被吃的暗子会标出揭开后的身份 |
| 棋谱 | 中文记谱（车二平五 / 车5平6），每 2 步一行 |
| 局面提示 | 暗子剩余、无吃子步数、局面重复次数、长将/长捉计数 |
| 自动存档 | 刷新或关闭页面后，下次打开可继续未下完的棋局 |
| 长将/长捉判负 | 按平台规则实现，可在「设置」中关闭（只提示不判负） |

## 胜负与和棋判定

- **胜**：将死、困毙（无子可动）、吃掉对方将帅、对方认输。
- **和**：连续 60 回合（120 步）无吃子；同一局面重复 5 次；双方均无进攻子力（子力全部翻开且无车马炮兵）。
- **长将**：同一子连续将军超过 6 回合判负。
- **长捉**：兵/卒、帅、士、象允许长捉；其他棋子连续捉同一子超过 6 回合判负。

## 文件结构

```
index.html     页面结构
style.css      样式（移动端优先，900px 以上切换为侧栏布局）
engine.js      规则引擎（纯逻辑，无 DOM 依赖，可被 node 直接 require）
ui.js          渲染与交互
test-engine.js 引擎单元测试
象棋揭棋规则.txt  规则原文
```
